## 2026-05-28 - Array processing in re-renders\n**Learning:** The CostCalculator component was recalculating a new Set and filtering large arrays (like tools) on every render, which gets triggered frequently when a user types in a search input. This is a common performance trap in React when derived state isn't memoized.\n**Action:** Always wrap heavy synchronous calculations (like map, filter, reduce on large datasets) in useMemo, especially if the component contains high-frequency state updates like text inputs.
