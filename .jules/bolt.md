## 2024-05-24 - React.memo ToolCard with Object keys Loop Comparison
**Learning:** In Next.js App Router applications, server-fetched data creates new object references on every navigation. When applying React.memo() to components receiving these objects, provide a custom comparison function checking ALL visually relevant properties (including dynamic data like ratings and upvotes, not just the ID). Comparing only the ID will cause stale UI bugs. Never use `JSON.stringify()` inside a `React.memo()` custom equality check, as it is computationally expensive and generates memory garbage. Instead of brittle, exhaustive manual property checks, use a shallow comparison loop over `Object.keys()`. When comparing array properties within this loop, ensure you iterate through and compare the actual elements (element-by-element), not just the array lengths.
**Action:** Use a shallow comparison loop over `Object.keys()` with element-by-element array comparison in custom equality functions for `React.memo()`.
