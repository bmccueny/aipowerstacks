## 2024-05-18 - React.memo with Next.js App Router Server-fetched Data
**Learning:** In Next.js App Router applications, server-fetched data creates new object references on every navigation. When applying `React.memo()` to components receiving these objects, provide a custom comparison function checking ALL visually relevant properties (including dynamic data like ratings and upvotes, not just the ID). Comparing only the ID will cause stale UI bugs. Also, never use `JSON.stringify()` inside a `React.memo()` custom equality check, as it is computationally expensive and generates memory garbage. Instead, use a shallow comparison loop over `Object.keys()`. When comparing array properties within this loop, ensure you iterate through and compare the actual elements (element-by-element), not just the array lengths.
**Action:** When memoizing components that render server-fetched entities, always use a custom `arePropsEqual` that performs a shallow key comparison (`Object.keys()`) and iterates through elements of any array properties rather than using `JSON.stringify()` or solely comparing primitive fields like `id`.
