## 2025-02-17 - React.memo custom equality check for Next.js Server Components
**Learning:** In Next.js App Router applications, server-fetched data creates new object references on every navigation. When applying `React.memo()` to components receiving these objects (like `ToolCard`), using only the ID in the equality check causes stale UI bugs (e.g., dynamically updated ratings and upvotes fail to re-render). Furthermore, using `JSON.stringify()` for a deep comparison is computationally expensive and generates excessive memory garbage, negating the performance benefits of memoization.
**Action:** Implement a custom comparison function that performs a shallow loop over `Object.keys()`, checking all visually relevant properties. Crucially, when comparing array properties within this loop, iterate through and compare actual elements (element-by-element) rather than merely relying on array length or object identity.
