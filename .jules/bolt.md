## 2024-07-08 - Object references in Next.js Server Components require careful client-side memoization
**Learning:** In Next.js App Router applications, passing server-fetched data as props to Client Components creates new object references on every navigation. When applying `React.memo()` to heavily-used components receiving these objects (like `ToolCard`), a simple ID check is insufficient (causes stale UI for dynamic data like ratings). Using `JSON.stringify()` for deep comparison is computationally expensive and creates garbage.
**Action:** Implement a custom equality function for `React.memo` that performs a shallow key comparison loop (`Object.keys()`), specifically checking array elements (element-by-element) rather than just array lengths, to catch dynamic property changes while maintaining performance.
